# 雪线 · SNOWLINE：全站视觉重构方案

状态：第二版首页方案已按确认实施。2026-09-22。

第一版已完成重构。本次在第一版基础上调整首页章节尺寸、章节切换和精选文章位置；下文描述第二版目标，文末单独保留第一版交付记录。

## 设计目标

延续登雪山的个人叙事，以抽象雪脊、舒展曲线、留白和杂志式排版建立现代、简洁、优雅的博客。替换旧版漫画探险手册方案；本次涵盖首页及全站公共视觉。

## 美术与双主题

主视觉使用 SVG：两到三层山体、少量利落山峰、柔和积雪曲线，以及向远处延伸的登山轨迹。细节集中在右侧和下沿，左侧为标题留白。浅深主题共用构图，避免切换跳动。曲线用于雪脊、章节衔接和路线，内容使用规整网格。

## 第二版首页结构：四屏连续攀登

首页由四个完整视口章节组成：**封面／山脚营地 → 技术冰脊 → 雪原横渡 → 高山夜营**。精选文章并入封面底部，不再独立占据一屏。

### 页面尺寸与公共框架

- 顶部导航始终保留。每个章节占满导航以下的可见空间；「导航高度 + 章节高度」合计为一个完整视口，不使用固定的 1080px 高度。
- 首页使用一个明确的纵向滚动区域，四屏在其中吸附对齐。内页继续采用自然阅读滚动。
- 常见桌面以 1440×900 为设计基准，同时验证 1366×768 和更宽屏幕。手机以动态可见高度计算，兼顾浏览器地址栏和底部安全区。
- 每屏保留章节编号、海拔、主要内容和下一屏提示；桌面右侧为四个章节节点，手机为紧凑的「01 / 04」章节控制。
- 高山夜营底部容纳首页的版权、订阅和次级链接，避免最后一屏之后再出现一个零散页脚。其他页面保留现有公共页脚。
- 内容来自现有 Sanity 数据，以展示数量和摘要长度控制密度，不靠缩小正文或裁掉内容满足一屏要求。

### 四屏构图与内容

| 章节 | 独立曲线设计 | 桌面排版 | 内容密度 |
| --- | --- | --- | --- |
| 01 封面／山脚营地 | 右侧主峰配一条从左下向右上延伸的 S 形雪脊，底部雪坡自然托起精选区 | 上部左文右景，下部横向文章带；保留大标题、简介、座右铭及两个入口 | 精选最多取 6 篇，桌面同时露出约 2.5–3 张 |
| 02 技术冰脊 | 两条靠近、向上收拢的陡峭曲线，构成冰脊与攀登路线；小节点对应项目状态 | 左侧窄栏为章节标题和技术分类，右侧宽栏为项目；项目条目沿曲线走势轻微错位，文字仍对齐 | 展示 2 个进行中项目、最多 3 个已完成项目；分类较多时提供展开入口 |
| 03 雪原横渡 | 大半径、低坡度的横向曲线从左到右穿过画面，表现开阔雪原；远近两层形成空间 | 上部标题和生活分类，中部一张大幅生活记录配两条较小记录，留出宽阔间距 | 展示 3 篇生活记录；无封面时使用完整的文字版式 |
| 04 高山夜营 | 包围内容的宽缓弧线与低处远山轮廓，构成围合感；一个微小光点作为营地 | 左侧为两条近期随记，右侧为关于、简介、友链等入口；底部订阅与版权 | 展示 2 条随记和最多 4 个站内入口 |

四屏各自绘制 SVG 路径，不能只把封面山形缩放或镜像后重复使用。共享线宽、颜色、留白比例与字体；曲线的陡缓、方向和内容关系各不相同。曲线不穿过正文，背景视觉重心随章节由右上、纵向、中横向到低处围合变化。

浅色下分别表现晨光、冷峻冰脊、开阔雪原和安静营地；深色下统一使用黑灰层次与少量哑金。浅深主题共用每屏的几何构图，切换不重排内容。

### 封面底部的精选文章带

精选区位于封面内部，底部与该屏一起停驻，不能滚动到下一屏才看见。桌面约占章节高度的下方 24%–30%，手机约占 28%–34%；具体根据标题、座右铭长度及可见高度调整。

```text
┌──────────────────── 顶部导航 ─────────────────────┐
│                                                  │
│   向上，                         抽象主峰         │
│   也向内。                    ／                  │
│   简介、座右铭           ____／  S 形雪脊         │
│   阅读精选 ↗  认识我 →                            │
│                                                  │
│   精选文章                         上一组 / 下一组 │
│   [文章 01]   [文章 02]   [文章 03 …]             │
│   ←──────── 可横向滚动，左至右阅读 ─────────→     │
│   01 / 山脚营地                    下一站 ↓       │
└──────────────────────────────────────────────────┘
```

- 「从左到右滚动」按**从左至右排列、可左右浏览的横向滚动区**设计，默认不自动播放。初始位于最左端，通过横向手势或“下一组”依次阅读右侧文章；“上一组”返回。
- 文章使用低矮的横向条目：编号、小封面（可选）、标题、分类和日期。正文摘要默认不显示，避免挤占封面。
- 手机同时显示一张完整条目和下一张的一部分，清楚提示可以横滑。每次横向滚动吸附到文章起点。
- 支持触摸、触控板水平手势、左右按钮及键盘操作。边界按钮禁用，不做无限循环。焦点移到尚未可见的文章时，让该文章进入视野。
- 纵向滚轮仍控制章节切换，不把它强行转换成文章横滚；横向手势不触发纵向翻屏。
- “阅读精选”在当前封面内定位并聚焦精选区，不再跳到独立章节。“下一站”进入技术冰脊。
- 只有一篇时居左展示并隐藏滚动按钮；没有精选时保留紧凑提示，不生成虚构文章或空卡片。

## 章节切换：吸附与导航

### 吸附行为

使用浏览器原生纵向滚动吸附。正常高度下，每屏以顶部对齐作为停靠点，并设置逐屏停靠；手势结束后自然落到相邻章节。吸附力度、惯性和持续时间随设备和浏览器而定，不承诺所有触控板都严格“一次手势一屏”。

- 鼠标滚轮、触控板与手机滑动均使用原生滚动，不拦截全局滚轮或锁住页面来模拟翻页。
- 点击章节节点或下一站时，平滑移动到目标屏；当前章节节点、编号和海拔随可见章节更新。
- 键盘可通过章节控制切换，阅读焦点不因普通滚动被强制移动。通过明确导航动作进入目标章节时，使标题位置及焦点可辨认。
- 保留章节锚点和直接链接；从文章返回首页时优先恢复原阅读位置，不能每次重置到封面。
- 搜索、订阅和移动菜单打开时，交互作用于当前面板，避免背景章节一起移动。

### 小屏、长内容与缩放

常规尺寸下四屏均完整占据一屏。先通过减少同时显示的条目、缩短摘要、收紧装饰留白来适配低高度屏幕，保留内容入口与可读字号。

当横屏手机、200% 缩放或多语言长文本使内容无法合理装入一屏时，允许当前章节高于一个视口，并将吸附放宽为接近边界时触发。正文保持可滚动、可聚焦、可完整访问；不设置卡片内部的纵向滚动条来形成多层滚动。普通显示条件下仍按完整屏幕设计。

## 分步入场动画

### 触发与节奏

章节进入主要可见区域并成为当前章节时，开始一次分组入场。建议以可见比例约 60% 为触发参考，并设置稳定判定，避免在两屏边界反复触发。尚未入场的装饰和内容不应阻塞滚动。

| 相对时间 | 元素组 | 表现 |
| --- | --- | --- |
| 0–350ms | 背景曲线与山体 | 轻微淡入；前后层最多移动 12–20px，主要曲线局部描绘 |
| 100–450ms | 编号、海拔、章节标题 | 从下方约 12px 淡入，标题作为完整元素出现 |
| 220–600ms | 简介、分类与说明 | 按语义组淡入，不逐字播放 |
| 340–850ms | 项目、文章、随记等主要内容 | 按阅读顺序逐项出现，相邻项间隔约 70–90ms；限制总时长 |
| 550–950ms | 次级入口与下一站提示 | 最后出现，不持续闪烁 |

上述时间为设计范围，实际根据可见元素数量微调。单屏完整入场控制在约 0.8–1 秒，滚动过程中也可继续操作，不需要等待动画完成。

### 四屏不同的入场顺序

- **封面**：雪脊背景 → 大标题 → 简介与座右铭 → 阅读／个人入口 → 底部精选条目从左至右依次出现。
- **技术冰脊**：攀登曲线 → 章节标题与技术分类 → 进行中项目自上而下出现 → 已完成节点点亮。
- **雪原横渡**：横向雪线 → 章节标题 → 主要生活记录 → 两条次要记录依次出现 → 分类与浏览入口完成入场。
- **高山夜营**：围合弧线与营地光点 → 标题 → 随记按日期顺序出现 → 站内入口 → 订阅及页脚信息。

### 重入与降级

- 同一次首页访问中，每屏首次抵达播放完整入场；回到已经看过的章节时，内容直接保持可见，避免反复等待。
- 快速跨过章节时，取消离开章节尚未开始的延迟动画；再次抵达时从清晰的可见状态继续，不留下半透明内容。
- 切换浅深主题不重播入场；文章带左右滚动也不重复播放整屏动画。
- 元素只做透明度与小幅位移，预留布局尺寸，不让内容出现时推动其他元素。避免大幅缩放、模糊、弹跳或持续视差。
- 开启减少动态效果时，直接显示全部内容，关闭描线、位移和程序化平滑滚动，保留即时章节导航。
- 页面脚本未加载、脚本出错或键盘提前聚焦内容时，文字与链接仍然可见、可用；不能依靠默认隐藏全部内容实现动画。

## 字体与组件

宋体用于中文大标题，英文使用克制的衬线字体；导航、摘要、表单采用系统无衬线字体；长文保留阅读字体；日期和编号少量使用等宽字体。桌面首屏标题约 64–80px，手机约 36–44px，正文约 17–18px。组件统一细边框、轻圆角、低阴影，列表以间距和分隔线组织。

## 内页

- 分类、项目与合集：统一页头、淡雪线装饰、清晰内容列表，保留封面与内容层级。
- 文章：约 720px 阅读栏，桌面侧边目录，安静底色和统一的标题、引用、标签。
- 关于、简介：统一内容容器、大标题、头像与分段介绍。
- 日志、友链：统一表面、线条、间距与元信息。
- 导航、页脚、搜索与订阅：共用颜色、字体、控件与焦点样式。

## 响应式与可访问性

手机封面依次为文字、雪山留白和底部精选带；其他屏各自重排为单列，保留专属曲线。允许精选区自身横向滚动，页面整体不出现横向溢出。导航支持键盘，装饰 SVG 对辅助技术隐藏，遵守 prefers-reduced-motion。三种语言均保留，不改 URL 和内容模型。低高度与缩放时按上述降级规则保证阅读。

## 实施与验收

本次按确认方案完成以下步骤：

1. 将首页组织为四个完整视口章节，明确导航高度、首页滚动区域和末屏页脚归属。
2. 把精选文章移入封面底部，实现横向吸附、边界按钮和移动端手势。
3. 为技术冰脊、雪原横渡、高山夜营分别绘制曲线并重排内容。
4. 接入章节可见状态、纵向吸附、导航定位及分组入场，补齐重入和减少动态效果分支。
5. 检查空数据、长标题、三种语言、低高度与缩放，随后执行 ESLint、TypeScript 和生产构建。

第二版验收标准：

- 常规桌面与手机尺寸下，一屏完整展示一个章节，顶部导航不遮挡标题，精选文章在封面内可见。
- 四屏各有可辨识的曲线构图和排版，浅深主题切换不改变几何布局。
- 纵向滚动可自然停靠到章节；横向文章带不干扰纵向翻屏。
- 首次切换后能明显看到标题、说明、内容依次出现，已访问章节不会反复隐藏。
- 搜索、订阅、菜单、键盘和浏览器返回仍正常工作；动画未完成时内容也可交互。
- 低高度、200% 缩放和减少动态效果条件下，内容可完整阅读，没有被吸附或动画困住。
- 本次仅修改首页体验及必要的公共布局适配，内页保持第一版阅读方式。

## 本次已确认的设计决策

- 四个完整视口章节，精选文章并入封面底部，首页页脚并入高山夜营。
- 精选文章默认手动横向滚动，不自动播放；按从左到右的阅读顺序展示。
- 采用原生吸附，保留自然滚动；极端低高度与缩放时优先保证内容可读。
- 每屏首次抵达播放约一秒的分步入场，返回已访问章节不重播。

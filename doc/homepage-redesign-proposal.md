# 雪线 · SNOWLINE：全站视觉重构方案

状态：已确认「抽象雪脊与流畅曲线」，进入实施。2026-09-22。

## 设计目标

延续登雪山的个人叙事，以抽象雪脊、舒展曲线、留白和杂志式排版建立现代、简洁、优雅的博客。替换旧版漫画探险手册方案；本次涵盖首页及全站公共视觉。

## 美术与双主题

主视觉使用 SVG：两到三层山体、少量利落山峰、柔和积雪曲线，以及向远处延伸的登山轨迹。细节集中在右侧和下沿，左侧为标题留白。浅深主题共用构图，避免切换跳动。曲线用于雪脊、章节衔接和路线，内容使用规整网格。

## 首页结构

1. **山脚营地**：首屏左文右景，约 80%–90% 桌面视口；标题「向上，也向内。」、站点介绍、阅读和个人介绍入口。座右铭保留。精选文章移至首屏下方，一篇重点推荐配两篇条目。
2. **技术冰脊**：宽栏项目与窄栏技术分类，明确状态、进度和摘要；保留已完成项目与换一组能力。
3. **雪原横渡**：一篇主要生活记录搭配轻量条目，真实照片保留自然色彩，无封面文章采用纯文字形式。
4. **高山夜营**：碎碎念以时间序列呈现，站内入口清晰排列，以远山轮廓收尾。

章节高度随内容变化，保留轻量章节导航，不强制整屏滚动。内容来自现有 Sanity 数据。

## 字体与组件

宋体用于中文大标题，英文使用克制的衬线字体；导航、摘要、表单采用系统无衬线字体；长文保留阅读字体；日期和编号少量使用等宽字体。桌面首屏标题约 64–80px，手机约 36–44px，正文约 17–18px。组件统一细边框、轻圆角、低阴影，列表以间距和分隔线组织。

## 内页

- 分类、项目与合集：统一页头、淡雪线装饰、清晰内容列表，保留封面与内容层级。
- 文章：约 720px 阅读栏，桌面侧边目录，安静底色和统一的标题、引用、标签。
- 关于、简介：统一内容容器、大标题、头像与分段介绍。
- 日志、友链：统一表面、线条、间距与元信息。
- 导航、页脚、搜索与订阅：共用颜色、字体、控件与焦点样式。

## 响应式与可访问性

手机首屏文字在上、雪山在下；网格改为单列，避免横向溢出。导航支持键盘，装饰 SVG 对辅助技术隐藏。动效限于短暂反馈，遵守 prefers-reduced-motion。三种语言均保留，不改 URL 和内容模型。

## 实施与验收

先更新主题变量与首页结构，再统一内页和公共组件；移除旧首页样式与图片引用，避免继续叠加覆盖。编码遵循本地 Next.js 文档。执行 ESLint、TypeScript 和生产构建，并检查桌面/手机、浅深主题、内容链接和空状态。检查结果在交付说明中记录。
